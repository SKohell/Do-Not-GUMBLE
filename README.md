# 🕊️ 金融肉鸽 · 黄金赌鸽所（本地 Demo）

一个以**国际黄金实时价格**为基线的多人在线金融肉鸽游戏。你要在扣生活费、AI 专家抢钱、技能卡操纵大盘的环境里活下来，顺便去赌场打工。

## 启动

双击 `启动游戏.bat`，或：

```bash
node server.js
```

浏览器打开 **http://127.0.0.1:8787**

> - 多人测试：开多个浏览器窗口 / 无痕窗口，各起一个名字即可。
> - 数据保存在 `data/state.json`，重启不丢；删掉该文件即重置。
> - 单机同时在线目标 ≤100 人。

## 行情逻辑（本版重点）

- 每 5 秒从**新浪财经**拉取 COMEX 纽约黄金（美元/盎司）和在岸人民币汇率。
- **世界金价** = 美元金价 ÷ 31.1034768 × USDCNY，单位 ¥/克。
- **游戏基线 = 世界金价 − ¥700/g 固定基差**，再叠加游戏内波动。
  - 基差把价格从约 ¥870 压到约 ¥170，仓位能买更多克，世界金价的波动占比被放大。
  - 同样一段真实行情，玩家账户盈亏波动约为原来的 5 倍。
  - 想调波动幅度，改 `server.js` 顶部 `GOLD_OFFSET`，或启动时设置环境变量 `GOLD_OFFSET=800`。
- 新浪拉取失败/休市时自动回退到带随机波动的模拟基线，界面有「模拟走势」标识。

## 玩法

### 资产与交易
- 初始资金 **¥10,000**，新手礼包：红 / 绿 / 黄 / 蓝 / 手 **各 1 张**。
- 每天北京时间 **00:00** 自动扣生活成本 **¥200**，顶栏有倒计时；现金不足会自动卖金补缴。
- 现货买卖 T+0；盈利每 **¥50 = 1 XP**。
- **Lv.5 解锁做空合约，Lv.10 解锁杠杆**（2x；Lv.15→3x，Lv.20→5x）；保证金亏 90% 自动强平。
- 升级：奖励现金 `200 + 100×等级`，并随机获得一张技能卡。
  - 升到 Lv.5 共需 350 XP；21点胜 +15、Blackjack +25。

### 技能卡
| 卡 | 效果 |
|---|---|
| 🟥 红卡 | 向全场注入一段**上行趋势**：峰值、拉升时长、回归时长均由服务端随机，客户端不公开 |
| 🟩 绿卡 | 向全场注入一段**下行趋势**：峰值、拉升与回归时长同样随机且不公开 |
| 🟨 黄卡 | **仅下一笔卖出**价格 ×1.1 |
| 🟦 蓝卡 | **仅下一笔买入**价格 ×0.9 |
| 🖐️ 手 | 指定玩家行窃：3% 起步，每次使用 +1%，最高 20%；失败也会消耗 |

> 红/绿卡不再向玩家、日志或 SSE 广播具体峰值、持续时间与倒计时；界面只显示“动能爬升中/衰减中”，让技能保留不确定性。
> 黄/蓝卡仅一笔生效，避免无限套利。

### AI 金融专家（无技能卡）
3 个策略 AI 与玩家同场交易：趋势跟踪、高抛低吸、3x 梭哈。
- AI 净资产低于 **¥2,000**（资金枯竭线）即破产。
- 破产后：**全服每个玩家获得一张随机技能卡**，AI 重组资金 = **初始资金 ×(1 + 0.1 × 破产次数)**。
- 离线玩家同样会收到卡，并在下次上线时看到通知。
- 面板上有每只 AI 的距破产进度条。

### 页面
- **📈 主界面**：世界金价 / 游戏基线、30 分钟走势、现货、合约、技能卡、AI 与真人混合排行榜、系统动态。
- **💬 聊天室**：大厅 / 闲聊灌水 / 交易喊单；**点击在线玩家可私聊**，私聊消息不对其他人广播。
- **🎰 打工房**：标准 21 点（庄家两张牌、暗牌、Blackjack 3:2、加倍、刷新恢复牌局）+ 欧式轮盘。
- **📰 贴吧**：发帖 / 回帖，系统会随机生成“内部消息”假帖（带「疑似托」标记）。

## 本版修复清单

1. **核心循环**：新手全色卡、升级发卡、AI 破产发卡；黄/蓝卡单次生效；AI 破产线可视化，破产会通知离线玩家。
2. **节奏**：保留真实自然日扣费（适配异步、非同时在线），顶部展示北京时间扣款倒计时；等级曲线和 AI 破产线全部移到 `server.js` 顶部参数区，可随时调。
3. **多人**：不再广播玩家 token；新增公开玩家 ID、真实 SSE 在线状态、点击在线玩家私聊。
4. **交易/21点**：超卖直接报错并显示最大可卖；黄/蓝卡仅下一笔；21点补上标准暗牌、庄家 Blackjack 即时结算、**普通平局正确退注**；刷新页面会从服务端恢复牌局。

## 可调参数（`server.js` 顶部）

```js
GOLD_OFFSET         // 固定基差，默认 700
BOT_BAILOUT_LINE    // AI 资金枯竭线，默认 2000
DAILY_COST          // 每日生活成本，默认 200
START_CASH          // 初始资金，默认 10000
needXp(l)           // 升级经验曲线
XP_RULES            // 各玩法经验值
```

## 技术

- 纯 Node.js 内置模块，零第三方依赖；HTTP + SSE 每秒推送。
- 行情源：`hq.sinajs.cn`（GBK 解码，带 Referer）。
- 数据文件：`data/state.json`；测试存档在 `data/state.*.json`（可删）。
- `cdp-check2.js` / `cdp-smoke.js` 是开发用浏览器端测脚本，不影响游戏。
