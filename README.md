# 🕊️ 金融肉鸽 · 黄金赌鸽所（本地 Demo）

多人在线「金融肉鸽」游戏：以**国际黄金实时价格**为基线，玩家互相博弈、操纵大盘、去赌场翻身，还要和AI金融专家赛跑。

## 启动方式

```
方式一：双击 启动游戏.bat
方式二：node server.js
```

然后浏览器打开 **http://127.0.0.1:8787**

> 多人测试：开多个浏览器窗口（或无痕窗口），各起一个名字即可同场博弈。
> 数据存在 `data/state.json`，重启服务进度不丢（想重置就删掉这个文件）。

## 已实现的设定

### 基线（行情）
- 每次刷新都从**新浪财经**拉取国际黄金（COMEX 纽约黄金 GC，美元/盎司）+ 在岸人民币汇率，换算成 **人民币/克** 作为基线价。
- 拉取失败或休市时自动降级为「模拟走势」，界面有 实时行情/模拟走势 徽章。

### 用户与规则
- 初始资金 **¥10,000**；每天（按北京时间自然日）自动扣除生活成本 **¥200**。
- 买入/卖出现货；**Lv.5 解锁做空合约，Lv.10 解锁杠杆（2x → Lv.15 3x → Lv.20 5x）**，亏损到保证金 90% 自动强平。
- 经验：现货/合约每盈利 ¥100 +1 经验；21点赢一局 +5（Blackjack +8）；轮盘中奖 +2。
- 升级奖励 **¥500 × 新等级**。

### 技能卡
| 卡 | 效果 |
|---|---|
| 🟥 红卡 | 基线 2 分钟内拉升 1~10%，随后 2 分钟缓步回归 |
| 🟩 绿卡 | 基线 2 分钟内下砸 1~10%，随后 2 分钟缓步回归 |
| 🟨 黄卡 | 10 分钟内你的卖出价 ×1.1 |
| 🟦 蓝卡 | 10 分钟内你的买入价 ×0.9 |
| 🖐️ 手 | 对指定玩家行窃：3% 起步，每用一次 +1%，上限 20% |

AI 专家破产时**全员发一张随机技能卡**。

### AI 金融专家（无技能卡）
3 个策略各异的 AI（趋势鸽 / 高抛低吸鸽 / 梭哈赌怪鸽）同步交易，同样交生活成本。
AI 没钱（权益 < ¥150）即破产：失败次数 +1，**AI 重组资金 = ¥10,000 × (1 + 0.1 × 失败次数)**，同时全员发卡。

### 功能页面
- **📈 主界面**：基线大屏 + 30 分钟走势图（红绿卡区间高亮）、现货买卖、合约做空/杠杆、技能卡、排行榜、AI 状态、系统动态。
- **💬 聊天室**：大厅 / 闲聊灌水 / 交易喊单 三个房间，实时消息。
- **🎰 打工房**：在线 21 点（下注/要牌/停牌/加倍，Blackjack 3:2）+ 欧式轮盘（红黑单双/区间/单号）。
- **📰 贴吧（金鸽吧）**：发帖回帖；系统会不定时生成「内部消息」假帖子迷惑视听（带「疑似托」标记的都是 AI 发的）。

## 技术说明
- 纯 Node.js 内置模块，**零依赖**：HTTP 静态服务 + SSE 实时推送（1 秒一跳）。
- 行情源：`hq.sinajs.cn`（GBK 解码，带 Referer），5 秒一拉；本地微抖动保证休市时游戏仍有生命。
- `cdp-test.js` / `cdp-smoke.js` 是开发用的端到端验证脚本（headless Chrome + CDP），不影响游戏。
